🤖 配置 Agent API

第 1 步 / 共 6 步 · 先配这个，后面所有生成都靠它

网页的 fenxi / du-nai 能力由一个「Agent API」执行：任意 OpenAI 兼容的 /chat/completions 接口（如 DeepSeek API：https://api.deepseek.com）。API Key 只保存在本机 state 目录。

🔑 番茄作家后台鉴权

第 2 步 / 共 6 步 · 配置后选择要发布的小说

浏览器登录 fanqienovel.com 作家后台 → F12 → Network → 任选一个 /api/author/... 请求 → 复制完整 Cookie 头和 X-Secsdk-Csrf-Token 头（会话级固定）。Cookie 约 1-2 个月失效，失效后重新填入即可。
